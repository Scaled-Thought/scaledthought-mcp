# Security

Please report a vulnerability in ScaledThought (the API, the MCP server, the CLI or the website) to
**security@scaledthought.com**. Don't open a public issue for it.

Our vulnerability disclosure policy, including how to report and the rules for testing:
<https://scaledthought.com/legal/security>. Machine-readable contact: <https://scaledthought.com/.well-known/security.txt>.
